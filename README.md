# Python Developer Assignment

## Overview

This project implements a package delivery assignment system.

The program:
- Assigns each package to the nearest available agent.
- Calculates delivery distances using Euclidean distance.
- Calculates each agent's package count, total distance, and efficiency.
- Identifies the best-performing agent.

## Files

- `main.py` - Main Python program.
- `base_case.json` - Base assignment input.
- `test_case_1.json` to `test_case_10.json` - Test inputs.
- `report.json` - Generated output report.

## How to Run

Run the base case:

```bash
python main.py base_case.json
